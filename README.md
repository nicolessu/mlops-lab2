# MLOps Lab2

This project demonstrates a simple Flask application containerized using Docker and Docker Compose.

## Run with Docker Compose

```bash
docker compose up --build
Open your browser and visit:
http://localhost:5002

You should see:
Hello from MLOps Lab2!

-------------------------------------

Stop
To stop the service:
docker compose down

-------------------------------------
Project Structure
-app.py — Flask application
-requirements.txt — Python dependencies
-Dockerfile — Docker image definition
-docker-compose.yml — Docker Compose configuration
-README.md — Project documentation

Technologies Used
Python 3.9
Flask
Docker
Docker Compose
